List of Terminal commands in kali linux

1.Man :- It gives the manual of the command.
2.pwd :-It prints the current working directory.
3.cd :-It changes the Directory.
4.ls :-It lists the files in current directory
      ls -a :-It shows hidden files.
      ls -l :-It gives a list of files in current folder.
      ls -h :-It shows the files size in bytes.
5.mkdir :-It creates a new directory.
      mkdir -p :-It creates multiple directories together as a parent.
6.rmdir :-It removes the empty directory.
      rmdir :-It removes multiple directories .
7.file :-It gives the type of file.
8.touch :-It creates new file
9.rm :-It deletes the files if directory is empty.
      rm -rf :- It removes full directory and everything inside it.
10.cp :-It is used to copy files.
      cp filename newfilename :-It directly copies files with new name in same folder.
      cp filename directory :-It copies file to selected directory.
      cp -r directory direstory :-It copies full directory with all the files insode it.
11.mv :-It is used to move or rename the file.
      mv oldname newname
      mv name directory
12.head :-It prints out first 10 lines of the file.
      head filename
      head -5 filename :-prints first 5 line of file.
13.tail :-It prints the last 10 lines of the file.
      tail filename
      tail -5 filename :-prints last 5 lines of file
14.cat :-It prints all the contents of a file.
      cat filename
      cat file1 file2 file3 > all.txt :-It combines the text of all files in one file.
      cat >filename :-It allows to write in file
      cat file1>file2 :- It copies the file and its content.
15.echo :-Prints the typed text in terminal.
16.more :-IT givesn output of the file page by page.
      more filename
17.find :-Searches File in the system.
      find -name filename
18.grep :-It is used to search text in files.
      grep "keyword" filename
